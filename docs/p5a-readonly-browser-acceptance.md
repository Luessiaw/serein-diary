# P5A 真实只读接入浏览器验收

本文用于执行 `P5A-T04`：在桌面和手机浏览器中验收真实只读数据、空状态、
日历日期、日期跳转、双向加载和回到此刻。

## 验收范围

本轮只验证只读浏览，不验证真实写入、删除、评论或媒体上传。

需要确认：

- 锁屏后进入真实后端数据，不回退到 mock。
- 初始页面定位到最新窗口和“新建日记”区域。
- 向上滚动可加载更早日记，位置不明显跳动。
- 日历深色日期来自后端日期统计。
- 点击深色日期后有舒缓的加载过渡，并跳转到目标日期附近。
- 历史窗口中可继续向上加载更早、向下加载更新。
- 未回到最新窗口前不显示“新建日记”区域。
- “回到此刻”圆形按钮固定在中央滚动区域右下角，并返回最新窗口。
- 空数据目录、后端不可达或分页失败时，有可理解的轻量状态。

## 准备

确认当前服务使用的是最新前端与后端代码。若使用 Compose 示例，操作者可在仓库根目录运行：

```bash
docker compose up -d --build api
docker compose up -d web
```

前端静态文件挂载到 Caddy，通常修改 `frontend/` 后强制刷新浏览器即可。

如果需要确认接口是否正常，可登录后在浏览器 console 运行：

```js
await SereinDataAdapter.listEntries({ limit: 3 })
await SereinDataAdapter.getEntryDates()
```

不要在聊天中复制完整日记正文。排查滚动问题时优先复制：

```js
SereinDebugLoad.dumpReport()
```

该报告不包含正文、密码、Cookie、session 或私有宿主路径。

## 桌面浏览器

1. 使用无痕窗口打开 `/diary/` 或当前部署地址。
2. 确认未登录时只显示锁屏，不显示日记流。
3. 登录后确认页面进入最新窗口，并定位到“新建日记”区域。
4. 向上滚动到顶部附近，确认会自动拉取更早日记。
5. 观察拉取后当前阅读位置是否稳定，没有明显跳动或重复条目。
6. 打开左上角侧边卡片，切换到日历页。
7. 确认有日记的日期显示为深色，无日记日期不深色。
8. 点击一个较早的深色日期。
9. 确认出现轻量加载过渡，随后定位到目标日期附近。
10. 在历史窗口中向上滚动，确认可继续加载更早内容。
11. 在历史窗口中向下滚动，确认可继续加载更新内容。
12. 确认未抵达最新窗口前不显示“新建日记”区域。
13. 确认“回到此刻”按钮显示在中央滚动区域右下角，而不是整个宽屏页面右下角。
14. 点击“回到此刻”，确认也出现加载过渡，并回到最新窗口和“新建日记”区域。
15. 再次上下滚动，确认“回到此刻”按钮只由“新建日记是否在滚动区顶端”决定。

## 手机浏览器

在手机或窄屏设备上重复桌面步骤 3--14，重点确认：

- 页面无横向溢出。
- 日历、侧边卡片和圆形返回按钮可触达。
- 日期跳转后目标日位置清晰。
- 上下方向加载不会因为触摸惯性滚动而重复触发过多请求。
- 返回按钮不会遮挡正文主要阅读区域。

## 空状态与错误状态

使用临时空数据目录时，确认：

- 页面仍显示“新建日记”区域。
- 没有真实条目时不回退到 mock。
- 日历没有深色日期。

临时停止或断开 API 时，确认：

- 初始加载失败有重试入口。
- 日历日期读取失败有轻量提示。
- 分页失败时可重试，且不会清空当前已读窗口。

## 通过标准

完成桌面和手机验收后，如果没有阻断问题，可将 `tasks.csv` 中 `P5A-T04` 标为
`done`，然后进入 `P5B-T01` 的真实写入闭环。

如果出现问题，保留当前任务为待办，并把 `SereinDebugLoad.dumpReport()` 的输出和
对应操作步骤保存到 `prompts/logs/`，再优先修复 P5A 的状态、滚动或游标问题。
