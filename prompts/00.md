# 日记网页设计构想

这个文档用于描述日记页面，会保持更新。

## 风格

1. **简约**。隐藏多余UI，去掉不需要的功能, 只需沉浸于写作本身，实现像word一样的写作体验。
2. **流畅**。避免让加载、保存等功能打断思考、视觉逻辑。
3. **模块化**。作为日记内容的数据，与排版等功能在结构上分离，保证数据可迁移性。

## 功能

1. 是一个干净简洁的页面，隐藏多余的UI, 只需要沉浸于写作本身。当前效果中，tiptap 有明显的边界（没有占满页面全部宽度），旁边有 Portable Markdown
预览界面，编辑框上方有标题、摘要、提示、编辑框底部也列出了页面元数据，等等，UI太多干扰注意力。
2. 我真正需要的是以下功能：a) 点击按钮新建一条日记；b) 进入编辑，沉浸写作 c) 自动或手动保存 d) 退出编辑 e) 通过时间轴等，快速跳转
元数据、排版等功能均在后台自动进行。
3. 在一个页面中同时显示多条日记，像一个长文那样浏览。类似于：
# 2026年X月X日1
xxxxxx
# 2026年X月X日
xxxxxx
…………
[+] (新建按钮)
其中，日期是自动生成的。
4. 日记的新建。在长文末端，放置一个 "新建" 按钮用于新建日记，点击后就可以直接在当前页面进行输入编辑。
5. 日记的修改。需要定制页面的右键菜单（手机端为长按菜单），右键后可以修改。
6. 日记的评论。也通过右键菜单完成。这些评论不能像 word 那样在侧边栏中显示，而是像网络媒体那样，以评论的形式显示。如果有选中的文本，需要标注引用的内容。评论的字体、样式等，需要与正文区分。
6. 时间轴。在页面的最左侧，要选取美观、简洁、方便的样式的功能。同时要注意避免干扰视觉影响写作，（例如只有在拖动时才显示文字，平时颜色减淡或显示为简略线条）
