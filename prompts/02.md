# 滚动区列表

当前日记是按时间倒序排列的，在显示时应改为正序排列。即，需要对从后端获得的数据，按日记的创建日期进行排列。这一功能可以在后端获取日记列表时就按时间顺序获取，也可以获取后再重新进行排列。请结合本项目风格选择合适路径。

增加两个元素：
1. 年份
2. 月份

## 年份

格式为“2026年”，字号、字体均由 tokens.css 控制。

它并不会显示在每篇日记前，而是按如下方法确定：
对于由后端获得的日记的列表，首先按年份分组，仅在当年的第一篇日记（记为diary1）的上方，加入 “年份” 元素。它不属于日记卡片，而是一个单独的控件。点击年份，可以收起该年度所有的日记。这个效果类似于 word 中标题功能，也为后续时间跳转准备接口。

这个控件位于 diary1 卡片的上方，宽度与卡片相同。

## 月份

格式为 “6月”。要求与逻辑与 年份 类似。它也是一个独立的控件。它位于当月第一篇日记的上方。


# 静态阅读外观

## 创建日期、时间
仅显示 “x日”，而不显示年和月，因为上面已经显示了年和月。

若同一天内创建了多份日记，则还需额外显示时间，格式为 "13:00". 如果只有一份日记则不需要显示。

日记、时间的显示格式可以进行智能化处理，例如智能选择
“今天”“昨天”“上周三”等。（如果这个功能比较复杂，可以稍后再实现）。


上面几个需求可能需要修改前端中列表的结构，或许需要多层嵌套。
同时也可能需要一些后端的 api 配合。或者在前端实现。请根据本项目的风格给出建议。
